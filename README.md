# VSwitcher

Локальний застосунок для Windows 10/11 x64: виділіть текст, набраний у неправильній розкладці, та натисніть **Ctrl+Alt+Space**.

## Запуск

Розпакуйте `dist/VSwitcher-win-x64.zip` в окрему папку й запустіть `VSwitcher.exe`. Усі файли поруч із ним потрібні; окремо встановлювати .NET не потрібно. Після запуску програма працює у треї (значок може бути під стрілкою прихованих значків).

Правою кнопкою на значку відкриваються налаштування, довідка та вихід. Автозапуск вмикається у налаштуваннях. Переміщення папки після ввімкнення автозапуску потребує повторного збереження налаштувань. Другий одночасний запуск не допускається.

## Поведінка

- Перетворюється все виділення відповідно до фізичних клавіш. Це не переклад і не виправлення орфографії.
- Підтримуються English (US), російська ЙЦУКЕН та українська розширена Windows. Таблиці символів беруться з Windows, включно з регістром і пунктуацією. Для нестандартних, фонетичних і користувацьких розкладок потрібна окрема підтримка.
- Мова визначається за локальними словниками. За низької впевненості з'являється вікно з мовами та попереднім переглядом. Є варіант залишити текст без змін. Enter застосовує вибір, Esc скасовує.
- Після застосування надсилається запит на перемикання цільового вікна на відповідну розкладку Windows.
- Автоматичного стеження за набором немає. Мережевих запитів у застосунку немає, текст не записується на диск.
- Налаштування й останній технічний статус без тексту виділення лежать у `%LOCALAPPDATA%\VSwitcher`.

## Обмеження першої версії

Заміна використовує Ctrl+C / Ctrl+V і звичайний текст, тому форматування виділення не зберігається. Після дії програма намагається відновити попередні формати буфера обміну; нові сторонні зміни буфера не перезаписує. Програми історії буфера можуть зафіксувати проміжні копії.

Працює лише там, де програма дозволяє копіювати виділення і вставляти текст. Без виділення деякі редактори копіюють весь рядок: це залежить від редактора, тому перед командою обов'язково виділіть фрагмент. Не використовуйте в полях лише для читання. Скасування вставлення — стандартне **Ctrl+Z**, якщо цільова програма його підтримує.

Програма з підвищеними правами може блокувати введення від VSwitcher зі звичайними правами. Термінали, RDP, захищені поля, повільні віддалені вставлення та конкретні версії месенджерів потребують окремого тестування. Відновлення буфера відбувається через 800 мс після вставлення; повільна програма може не встигнути прочитати його. Не змінюйте виділення та не друкуйте під час виконання команди.

Визначення мови консервативне: використовуються словникові записи Hunspell без розгортання правил словозміни. Рідкісні слова, назви, сленг та окремі словоформи частіше викликатимуть ручний вибір. Якщо обидва варіанти осмислені, програма не може знати намір користувача.

## Збірка та перевірки

Потрібен .NET SDK 10 на Windows.

```powershell
dotnet build src/VSwitcher/VSwitcher.csproj -c Release
dotnet run --project tests/VSwitcher.Tests -c Release
dotnet publish src/VSwitcher/VSwitcher.csproj -c Release -r win-x64 --self-contained true -o dist/VSwitcher
```

Тести перевіряють шість напрямків, регістр, пунктуацію, переноси, незмінність сторонніх символів, автоматичний вибір та відмову від автоматичної заміни за неоднозначності. Вони не підтверджують сумісності з усіма редакторами й месенджерами. Перевірка на окремій Windows 10 ще потрібна.

Перевірено 2026-11-02: 27 автоматизованих перевірок пройшли. У Блокноті на Windows 11 підтверджені глобальна комбінація, заміна `ghbdsn` → `привіт`, скасування через Ctrl+Z, відкриття вибору для `gh` та застосування обраного варіанта `пр` зі збереженням фокуса редактора. Виправлено помилку, за якої відкладене читання OLE-буфера помилково сприймалося як стороння зміна.

Ручна перевірка: у Блокноті введіть `ghbdsn`, виділіть його, натисніть Ctrl+Alt+Space — очікується `привіт`. Аналогічно `ghbdtn` → `привет`, `руддщ цщкдв` → `hello world`. Для `gh` очікується вибір варіанта. Перевірте Esc, Ctrl+Z, продовження введення потрібною мовою, відновлення попереднього буфера та зміну гарячої клавіші. Повторіть у редакторі коду, браузері й потрібних месенджерах.
